열쇠를 현관 매트 밑에 숨기는 일에 대하여

맥미니에 AI 에이전트를 심으려다 7번 실패하고, 결국 호텔을 바꿔버린 이야기.

최병찬 2026.04.16 10분

이상한 일이다. 매달 200달러를 내고 있는데, 정작 그 200달러로 할 수 있는 일에 제한이 있다는 건.

Claude Max라는 구독이 있습니다. 월 200달러. 넷플릭스 12개월치거든요. 근데 저는 그걸 내고 있었고, 솔직히 꽤 만족하고 있었습니다. 문제는 그 다음이었습니다.

제 책상 위에는 맥미니가 하나 있습니다. M4 칩이 들어간, 은색의 작고 조용한 금속 상자. 이 친구는 24시간 켜져 있거든요. 전기세도 얼마 안 나오고, 팬 소리도 거의 없고, 그냥 책상 구석에서 고양이처럼 웅크리고 있습니다. 가끔 불빛이 깜빡이는 게, 마치 졸다가 한쪽 눈을 뜨는 것 같은 것이다.

그러고 보면 이런 생각은 자연스러운 겁니다. 24시간 켜져 있는 컴퓨터에 AI를 심으면 어떨까? 제가 자는 동안에도 코드를 돌리고, 텔레그램으로 "어제 그 작업 결과 어때?" 하고 물으면 대답하는, 나만의 AI 에이전트.

Hermes Agent라는 오픈소스가 정확히 그 일을 합니다. 설치하고, AI 두뇌를 연결하고, 텔레그램을 붙이면 끝. 이론적으로는요.

읽고 나면 이런 생각이 드실 겁니다.
"이거... 나도 당장 해볼 수 있겠는데?"

호텔 프론트 데스크의 딜레마

AI를 연결하려면 인증이 필요합니다. 비유하자면 이런 거거든요.

AI 서비스는 호텔이고, 내 구독은 방 열쇠입니다. Hermes는 제 대리인인데, 이 대리인이 호텔 방에 들어가려면 열쇠가 필요하잖아요.

문제는 Claude라는 호텔이 열쇠를 금고에 넣어버린다는 겁니다.

macOS에서 Claude Code는 인증 토큰을 Keychain이라는 시스템 금고에만 저장합니다. 파일로 안 남겨요. 심지어 실수로 파일이 생겨도, 앱을 시작할 때마다 지워버립니다.

호텔 프론트가 "열쇠는 저희가 관리합니다. 직접 들고 다니시면 안 됩니다" 하고 매번 회수해 가는 것과 같은 것이다.

Hermes는 그 열쇠 파일을 읽어야 작동합니다. 그런데 파일이 없어요. 금고 안에 있거든요. 금고 비밀번호는 macOS만 알고요.

Anthropic에 이 문제를 제보했더니 "고칠 계획 없음"으로 닫아버렸습니다. 금고에 넣은 건 의도적이라는 뜻이거든요.

4월 14일, 저는 이 금고를 열기 위해 7가지 방법을 시도했습니다. 자물쇠공이 된 기분이었어요.

  • 시도 1: 마스터키 발급 OAuth 토큰을 직접 만들었는데, 호텔 측이 "이건 가짜 열쇠입니다" 하고 거부 (401 에러)
  • 시도 2-3: 뒷문으로 들어가기 환경변수에 비밀번호를 써놓으면 알아서 읽겠지 했는데, 같은 거부
  • 시도 4: 눈치작전 "비밀번호 없이도 알아서 찾겠지" 했는데, 찾을 파일 자체가 없었음
  • 시도 5: 금고 따기 Keychain에서 직접 추출 시도. SSH 상태라 "허가되지 않은 접근" 거부
  • 시도 6-7: 호텔 리모델링 기다리기 업데이트하면 나아지려나 했지만, 금고 정책은 변하지 않았음

7번의 시도. 전부 실패. 이 호텔은 열쇠를 절대 내주지 않습니다.

보통은 여기서 포기하잖아요. 저도 그랬습니다. 이틀 동안.

다른 호텔의 현관 매트

4월 16일 아침, 커피를 마시다가 문득 이런 생각이 들었습니다.

금고를 여는 방법을 찾고 있었는데,

애초에 열쇠를 금고에 안 넣는 호텔이 있으면 되는 거 아닌가?

있었습니다. 바로 옆 건물에.

OpenAI의 Codex CLI라는 서비스가 있거든요. 이쪽도 AI 서비스인데, 로그인하면 토큰을 ~/.codex/auth.json이라는 파일에 저장합니다. Keychain이 아니라 그냥 파일.

말하자면 열쇠를 현관 매트 밑에 숨겨두는 타입인 것이다. 보안 전문가가 보면 인상을 찌푸릴 수도 있지만, 지금 제가 필요한 건 정확히 그거였습니다. 다른 프로그램이 읽을 수 있는 열쇠.

Claude (금고형) Codex (매트형)
열쇠 보관 금고 안 (Keychain). 본인만 열 수 있음 현관 매트 밑 (JSON 파일). 누구든 들춰볼 수 있음
대리인이 쓸 수 있나 안 됨. 금고가 허락 안 함 됨. 파일만 읽으면 됨
Hermes 연동 구조적 불가 공식 지원
추가 비용 없음 (이미 구독 중) 없음 (ChatGPT 구독에 포함)

근데 진짜 기가 막힌 건요. Hermes의 설정 파일을 열었더니 이미 이 선택지가 써 있었다는 겁니다. 식당 메뉴판에 처음부터 있었는데 안 보고 있었던 요리 같은 것이다.

# Hermes config.yaml에 이미 적혀 있던 것 "openai-codex" - OpenAI Codex (requires: hermes login --provider openai-codex)

소스 코드를 뜯어보니 더 재밌었습니다. _import_codex_cli_tokens()라는 함수가 있는데, 이름부터 노골적이거든요. "Codex CLI의 토큰을 가져오겠다." 이 함수가 하는 일은 딱 하나입니다. ~/.codex/auth.json 파일을 열어서 읽는 것.

현관 매트를 들추는 함수입니다.

열쇠 옮기기

나머지는 솔직히 허무할 정도로 간단했습니다. 이사할 때 택배 보내는 것과 비슷하다고 할 수 있다.

  • 1. 맥북에서 Codex 로그인 브라우저가 열리고, ChatGPT 계정으로 인증. 10초. 열쇠 수령 완료.
  • 2. 열쇠를 맥미니로 택배 auth.json 파일 1개를 scp로 복사. 1초. 택배비 무료.
  • 3. Hermes에게 "이 열쇠 써" config.yaml 2줄 수정. provider를 openai-codex로, 모델을 gpt-5.4로.
  • 4. 문 열어보기 "인사 한마디 해봐" → "Hello!" 문이 열렸다.
# 이 4줄이 전부입니다 $ codex login # 맥북에서 열쇠 받기 $ scp ~/.codex/auth.json mini:~/.codex/ # 맥미니로 보내기 $ vi ~/.hermes/config.yaml # "이 열쇠 써" 설정 $ hermes chat -q "hello" # 문 열기 ╭─ ⚕ Hermes ─────────────────────╮ Hello! session_id: 20260416_142239_2e679f

4월 14일에 하루 종일 금고를 두드렸던 게, 호텔을 바꾸니까 5분 만에 끝났습니다. 인생이 그런 것이다.

냉장고를 처음 채우는 일

그러고 보면, 맥미니에 AI 에이전트를 설치하는 건 새 냉장고를 집에 들여놓는 것과 비슷한 것이다.

처음에는 텅 비어 있거든요. 물 한 병, 계란 한 판, 맥주 몇 캔. 근데 일주일쯤 지나면 냉장고 안에 생활 패턴이 생깁니다. 자주 먹는 것들이 정해진 자리에 놓이고, 유통기한이 임박한 건 앞쪽으로 오고, 냉동실 깊숙이는 언제 넣었는지 기억나지 않는 만두가 자리를 잡는다.

Hermes도 그렇습니다. 처음에는 "Hello!"가 전부입니다. 하지만 제 파일 구조를 익히고, 자주 쓰는 명령어를 기억하고, 텔레그램으로 원격 대화가 쌓이면, 어느 순간 이 금속 상자 안의 존재가 내 에이전트가 됩니다.

실제로 성격도 넣어봤거든요. SOUL.md라는 파일에 "하루키처럼 말해"라고 써놨더니, 진짜 하루키처럼 말합니다.

"오늘 맥미니에 너를 설치했거든. 소감이 어때?" 하고 물었더니 이렇게 대답했습니다.

"맥미니라는 기계는 과장하지 않고 말해서, 조용한데 할 일은 정확히 해내는 편의점 야간 알바 같은 구석이 있다."

편의점 야간 알바라니. 이런 비유를 AI가 스스로 만들어내는 걸 보면, 꽤 괜찮은 동거인을 들인 것 같다는 생각이 듭니다.

여기서 잠깐

열쇠를 어디에 보관하느냐가, 그 호텔에서 할 수 있는 일의 범위를 결정합니다. Claude가 금고에 가둔 순간, 외부 연동이 막혔거든요. Codex가 파일에 열어둔 순간, 서드파티 생태계가 가능해졌습니다. 기술적으로는 사소한 차이인데, 사용자 입장에서는 "할 수 있다"와 "할 수 없다"의 차이가 됩니다. 보안과 편의 사이의 선택이라기보다, 개방과 폐쇄 사이의 철학 차이인 것이다.

그리고 가장 중요한 부분이요. 이 에이전트의 두뇌, 그러니까 gpt-5.4 모델을 돌리는 비용은 이미 내고 있는 ChatGPT 구독에 포함되어 있습니다. 추가 과금 0원. 매달 내는 구독료가 맥미니 위의 에이전트를 먹여 살리는 셈이거든요.

따라 해보고 싶은 분들을 위해

필요한 건 4가지입니다. ChatGPT 구독(Pro든 Plus든), 맥미니(아무 Mac이면 됨), Hermes Agent, Codex CLI. 그리고 10분.

# 1. Codex CLI 설치 $ npm install -g @openai/codex # 2. 로그인 (브라우저 있는 기기에서, 딱 1번) $ codex login # 3. 열쇠 파일을 맥미니로 보내기 $ scp ~/.codex/auth.json 맥미니:~/.codex/auth.json # 4. 맥미니의 Hermes 설정 파일 수정 model: default: "gpt-5.4" provider: "openai-codex" # 5. 작동 확인 $ hermes chat -q "안녕" --provider openai-codex

열쇠(토큰)는 약 10일마다 만료됩니다. Hermes가 알아서 갱신을 시도하지만, 가끔 실패하면 맥북에서 codex login 1번 하고 파일을 다시 보내면 됩니다. 10초짜리 일이거든요.

7번의 실패가 있었고, 이틀의 공백이 있었고, 커피 한 잔의 생각이 있었습니다.

돌이켜 보면 해답은 처음부터 거기 있었습니다. 다만 금고를 열려고만 했지, 다른 호텔을 알아볼 생각을 못 했던 거거든요. "어떻게 뚫을까"라는 질문은 7번 실패했지만, "다른 길은 없을까"라는 질문은 1번에 답이 나왔습니다.

솔직히 말하면, 문제를 푼 건 기술력이 아니었습니다. 호텔을 바꾼 것에 불과하거든요. 진짜 어려웠던 건 "이 호텔이 아닐 수도 있다"는 가능성을 받아들이는 일이었습니다.

문제를 푸는 건 기술이 아니라 질문을 바꾸는 일이었습니다.

지금 이 순간에도, 제 책상 위의 맥미니 안에서 Hermes가 조용히 숨 쉬고 있습니다. 가끔 불빛이 깜빡이거든요. 고양이가 한쪽 눈을 뜨는 것처럼.

어쨌든, 나쁘지 않은 동거인이 생긴 것이다.

이 글은 Claude Code (Opus 4.6)와 Hermes Agent (gpt-5.4)의 합작입니다. AI 둘이 같이 쓴 셈인데, 한쪽은 금고에 열쇠를 넣는 쪽이고 한쪽은 매트 밑에 두는 쪽이거든요. 아이러니하다.
